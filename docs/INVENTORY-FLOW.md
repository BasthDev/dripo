# Dripo inventory flow (simplified)

## Drawer

**Purchasing** (dropdown)
- **Purchases** — orders + received history
- **Suppliers**

**Management → Inventory** — add/edit ingredients (+ button)

## Purchases

1. **Orders** tab → create order → **Receive goods** (one tap) → stock + **Received** tab
2. **Received** tab → **+** → **Stock** screen → fill qty/cost per ingredient → post

## Stock screen (one place)

| Tab | Use |
|-----|-----|
| Receive purchase | Supplier, invoice, qty + price per ingredient (g/ml/pcs) |
| Physical count | Counted qty vs system |

Old separate “add stock” form removed — redirects here.
